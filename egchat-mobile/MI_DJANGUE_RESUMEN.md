**Tablas SQL creadas:**
- `djangue_groups` - Grupos de djangue

- `djangue_members` - Integrantes y turnos
- `djangue_contributions` - Historial de pagos
- `djangue_payouts` - Historial de cobros

**Endpoints API (7 total):**
1. `GET /api/djangue` - Listar mis djangues
2. `POST /api/djangue` - Crear nuevo grupo
3. `GET /api/djangue/:id` - Detalle/dashboard
4. `POST /api/djangue/:id/members` - Agregar integrante
5. `POST /api/djangue/:id/pay` - Pagar cuota
6. `GET /api/djangue/:id/contributions` - Historial
7. `DELETE /api/djangue/:id` - Cancelar djangue

**Sistema de notificaciones:**
- `sendPushToUser()` - Envío de push con Expo
- `/api/push/register` - Registrar token
- `/api/push/register-expo-token` - Alias compatibilidad
